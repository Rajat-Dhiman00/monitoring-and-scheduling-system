🧠 DSA Lab — Live Visualizer

See exactly how your tasks are stored and processed using Data Structures.

Max-Heap / Priority Queue Tasks are inserted into a max-heap by priority. The root is always the most urgent task. Time: O(log n) insert/delete.
Singly Linked List Tasks are stored as linked nodes. Insert at head is O(1). Traversal is O(n). This mirrors the EventManager.cpp backend.
Stack — Undo / Redo Every task action (create, edit, delete) is pushed onto a stack. Undo pops the last operation. Time: O(1) push/pop.
Binary Search on Sorted Tasks Tasks are sorted by title alphabetically. Binary search finds any task in O(log n) steps instead of O(n) linear scan.
